# synapse.
A responsive web and mobile application where AI creates synapses among the topics and information which users' uploads.

## Tech Stack
- **Server (`server/`):** ASP.NET Core Web API (.NET 10.0.302)
- **Client (`client/`):** Blazor WebAssembly Standalone (.NET 10.0.302) — runs entirely in the browser, calls the server API over HTTP
- **Database:** MySQL 26.7 (via Docker), Entity Framework Core 10.0.9 (MySql.EntityFrameworkCore)
